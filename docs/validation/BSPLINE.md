## 比例与基函数的数学对应

采用 **r**(u)、**d**ᵢ、次数 k 和节点 uᵢ，不使用阶数概念。

对于一次递推 M=(1−α)A+αB：

- AM/AB=α，对应青色段。
- MB/AB=1−α，对应粉色段。
- A 的系数取对边 MB 的比例 1−α；B 的系数取对边 AM 的比例 α。三角图入边颜色与这个系数对应，而不是混淆为邻边比例。

`deBoor` 同时递推各个控制顶点的线性组合权重：顶层是单位向量，各层按 `(1−α)w左+αw右` 传播。选中一个 Nᵢ,ₖ 时，高亮其经过的路径；汇合处相加，最终权重严格等于独立 Cox–de Boor 求值的 Nᵢ,ₖ(u)。图中显示当前递推点和最终点的彩色权重条，以及两种计算的误差。

`src/bspline.js` 与 DOM/Three.js 无关。保留通用基函数、de Boor、解析左右导数、节点验证和非零区间采样；新增可测试的 `deBoorStep` 元数据。重复节点的基函数零分母项为零；de Boor 选择非零区间，其活动分母为正。内部节点默认右侧区间，有效域右端取精确左极限。逐段采样，不跨 k+1 重内部节点连线。

只在节点满足单段 Bézier 条件，或当前局部段两端重数足够时，使用对应控制顶点与 de Casteljau 对照；仅端点夹持且存在普通内部节点，不假称整条曲线是一段 Bézier。

线、点、材质及动态缓冲区预分配。宽线更新已有 interleaved buffer，动画不反复 setPositions 或新建 GPU 资源。图表为内联 Canvas 2D，无外部资源请求。
